Run it

Two ways to start

Docker is the only requirement. No Python or Node on the host.

Try it on your machine

The development stack, with hot reload. Then open http://localhost:3012.

git clone https://github.com/nelay04/Meadow.git
cd Meadow
cp .env.example .env
docker compose -f docker-compose.local.yml up -d

Run it for your team

The production stack puts nginx in front and runs migrations before the API starts. Copy .env.prod.example to .env.prod, fill it in, then: 

docker compose --env-file .env.prod up -d --build --wait

Read the deploy guide (opens in a new tab), the runbook this site was deployed with.

Measured

By the numbers

From the repository's own benchmarks, not from a brochure. Sixty frames a second at 5,000 objects is the target and is not yet verified on real hardware; everything below has been measured.

  • 1draw call for 5,000 shapes on screen
  • 3.5 msof CPU per frame at 5,000 objects
  • 15,000websockets on one API process, no failures
  • 89 KBof server memory per open connection

Taken on a four-core machine with 4.9 GB of memory, under WSL2, with the load generator running on the same cores. These are floors rather than ceilings: the websocket sweep stopped at its own limit and not at the server's, and 20,000 objects has never been measured because a run that size is killed for memory. Real hardware should do better, and none of it has been measured there yet.

Built with

What is inside

Shapes go to a WebGL layer as one instanced draw call, with arrows and ink on passes of their own; rich text is a DOM overlay on the same camera. The document is a CRDT, synced over a websocket and kept in the browser for offline work.

Canvas

React 19, TypeScript, Vite, PixiJS 8, TipTap, rbush, Zustand, Tailwind

Realtime

yjs over websocket, offline persistence in the browser, awareness for presence

Server

FastAPI, pycrdt, SQLAlchemy 2 async, Alembic, arq

Data

PostgreSQL 16, Redis 7

Auth

argon2id, JWT access tokens, rotating refresh tokens with reuse detection

Infrastructure

Docker Compose, nginx, GitHub Actions to GHCR to a VPS
